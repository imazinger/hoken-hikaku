# 75歳以降の生命保障を比較

現在月額約3,000円・75歳までの生命保険（がんに関する保障を含むという本人談）の終了後に備える比較ページです。現在の商品特定は目的にしません。

公式情報再確認日：2026年9月6日。公開先：https://imazinger.github.io/hoken-hikaku/

## 内容

1. 結論
2. おすすめ順位（見積もり優先順位）
3. 全24項目の比較表
4. 各商品の詳細
5. 85歳までの共済と終身生命保険の年齢別比較
6. がん保障・払込免除の区別
7. 注意事項、公式出典

対象：アフラック「かしこく備える終身保険」、オリックス生命「RISE」、SOMPOひまわり生命「一生のお守り」、静岡県民共済「熟年2型」（熟年4型も補足）。

以前のがん保険中心・70歳終了という前提、旧ページの年齢・性別・喫煙条件、見積もり・グラフは撤回しました。追加の申告で53歳・男性・喫煙ありを確認。4候補の公式月額をグラフ化し、死亡保障額の違いを明記します。公式掲載例の料率日と調査日を分けています。

## 構成と更新

既存の静的構成を維持。index.html、assets/style.css、assets/script.jsだけで動作し、ビルド・外部ライブラリ・APIキーは不要。リポジトリ配下のGitHub Pagesに対応する相対パスを使用します。

- 比較表は項目を縦、4商品を横に配置。狭い画面では1商品を初期表示し、選択肢で切替／全商品比較が可能。
- JavaScript無効でも全内容を読めます。年齢別表は表内の横スクロール。印刷時は比較表を省略し、全4商品の詳細を印刷します。
- 商品条件を変更するときは、結論・順位・比較表・詳細・年齢別表を一致させてください。
- 重要条件からsources内の公式出典へ参照。資料の表記年月と確認日を区別してください。
- 共済は70・80歳区分で減額し、85歳になって初めての3月31日で終了。2026年4月の特約85歳延長と、80歳以降の手術・先進医療対象外を区別します。
- RISE対面免除特則の現行条件、一生のお守りの取扱条件は設計書で最終確認。医療特約の追加可否を他商品から推測しません。

## 公開

公開元は `main` ブランチのルートです。2026年9月5日の公開反映依頼に基づき、検証済みのHTML・CSS・JavaScriptとREADMEをコミットして既存のGitHub Pagesへ反映します。通常の更新でも、この静的ファイル構成を維持してください。
