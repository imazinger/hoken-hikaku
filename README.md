## ページの構成

- 冒頭：比較条件と5列の要約比較表。
- 比較表の直後：53歳の現在から90歳までを同じ軸で見る折れ線グラフ、暫定のおすすめ順位。
- 続き：詳細へのリンク、折りたたみ式の読み方、用語の説明、5商品の詳細、未確認事項、公式出典。
- 比較表：商品・プラン／保険料／70歳以降の継続／新しい治療への備え／主な注意点。
- 860px以下：比較表を商品ごとのカードに切り替えます。保険料と継続年齢は、幅が足りる場合に横並び、狭い画面や大きな文字では1列になります。印刷時もカード形式を使います。
- スマートフォン：本文は17px相当、比較カード本文は16px相当。主な移動リンクは44px相当以上の高さを確保し、画面下の「比較・順位・商品詳細・出典」から移動できます。文字サイズはブラウザの設定に追従します。
- iPhoneなどの画面端・ホームインジケーター周辺には余白を確保します。200%の拡大を禁止する設定は使用していません。

## 太陽生命の公式試算画面で追加確認した事項

見積もりは53歳男性、終身保障・終身払い、クレジットカード月払で2026年9月4日に確認。ユーザーが開いた公式画面で保障額と選択する商品だけを変更しました。

- 診断型〔1回型〕は50万円のみで月2,318円。画面の50万円は「ガン診断保険金＋上皮内ガン等診断給付金」の表示額で、上皮内ガン等診断給付金は5万円です。
- 当初の診断40万円・終身のみは月1,855円。比較条件をそろえるため50万円の2,318円を使用します。
- 治療型10万円のみで月5,071円。両方選択すると月7,053円（診断型2,212円＋治療型4,841円）。保障額・組み合わせによって保険料割引ランクが変わる場合があると画面に案内されています。
- 契約年齢の表示は有期18〜75歳、終身18〜79歳。両商品の単独選択で同じ表示を確認しました。告知・引受条件を満たすかの判定はしていません。
- 試算結果は入力条件に依存するため、公開リンクには公式の商品説明・見積もり入口を使います。生年月日そのもの、個人情報を含む画面写真やセッション情報は公開資料に載せません。
- 公開ページの `taiyo-quote` に取得条件・日付・内訳を記録しています。

## 折れ線グラフとおすすめ順位

- 現在と将来は別グラフ・別タブに分けず、53歳から90歳までを1つの時間軸に表示します。横軸の目盛りは53・60・70・80・90歳です。グラフは1つのためタブは設けていません。
- SBI損保の公開料率表は74歳までです。確認した73歳の参考額を78歳の更新直前まで横に延ばし、78歳以降の金額は未確認として空白にします。78・83・88歳更新時の料率は公式窓口へ照会が必要です。90歳時点は88歳更新の契約期間中です。
- SBI損保は5年更新を表す階段状の折れ線です。現行料率を当てはめた参考額であり、将来の保険料を保証しません。インターネット割引は含めません。
- 勇気のお守りは、53歳で今回の終身払いプランに加入して継続する場合の4,246円です。将来の年齢で新規加入する場合の料金ではありません。
- 共済は53歳の3,000円相当の点のみを表示します。将来の保険料は未確認のため線を延ばしません。70歳の縦線は本人談の契約終了年齢の目印であり、正確な終了日は要確認です。
- 太陽生命は診断型2,318円・治療型5,071円の単独プランを、それぞれ90歳まで一定の線で示します。53歳で加入した今回の終身保障・終身払いを同じ条件で続ける想定です。給付による消滅・限度到達・保障変更は反映しません。年齢が上がってから新規加入する場合の見積もりではありません。
- 横軸の終了（90歳）は保障終了を意味しません。グラフの値は折りたたみの表でも確認できます。外部ライブラリやJavaScriptなしで読めます。
- 暫定順位は、1位：勇気のお守り、2位：SBI損保、3位：太陽生命・診断型、4位：太陽生命・治療型、5位：未特定の共済。70歳以降の継続、将来負担、診断・治療・入院・手術、先進医療・自由診療、給付方式、加入条件、情報の確かさを総合評価します。保険会社の公式ランキングではありません。
- 1位は月4,246円を支払えることが前提です。現在の月3,000円の予算や対象自由診療の実費を優先する場合はSBI損保が第一候補になり得ます。太陽生命・診断型は月2,318円で予算内かつ終身、治療型は月5,071円で予算を2,071円超えることを確認したため、3・4位を見直しました。共済の正式資料や各社の引受条件で順位を見直します。
