## ページの構成

- 冒頭：比較条件と5列の要約比較表。
- 続き：詳細へのリンク、折りたたみ式の読み方、用語の説明、5商品の詳細、未確認事項、公式出典。
- 比較表：商品・プラン／保険料／70歳以降の継続／新しい治療への備え／主な注意点。
- 860px以下：比較表を商品ごとのカードに切り替えます。保険料と継続年齢は、幅が足りる場合に横並び、狭い画面や大きな文字では1列になります。印刷時もカード形式を使います。
- スマートフォン：本文は17px相当、比較カード本文は16px相当。主な移動リンクは44px相当以上の高さを確保し、画面下の「比較・商品詳細・出典」から移動できます。文字サイズはブラウザの設定に追従します。
- iPhoneなどの画面端・ホームインジケーター周辺には余白を確保します。200%の拡大を禁止する設定は使用していません。
